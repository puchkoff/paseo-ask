Adds an "Ask" button to the workspace header and to each agent's composer, and a `/btw <question>` command that asks in Ask instead of the agent. It opens a floating window (full screen on phones), or an "Ask" tab in the right-hand panel if you pick that under this plugin's ⋯ → Ask in Settings → Plugins; the choice is saved per device. There you type a question and get an answer, with follow-ups in the same thread. While Claude works you see its tool calls as they happen, stop it, or send another message, which steers, queues or interrupts per Paseo's Default send setting, with the same keys as the main composer; the Ask button spins meanwhile and shows a dot when an answer arrives with the window closed. Images the answer links to are shown inline.

Answers come from the Claude Code CLI (`claude -p`) on the daemon machine, so `claude` must be installed and logged in there. It runs like an agent in the main window: your Claude Code settings, skills, plugins and MCP servers, full tool access without permission prompts (`bypassPermissions`), in your home directory: it can search the web, read and change files and run commands. Opened from an agent's composer, it uses that agent's Claude model and effort and sees its last ~50 messages (yours and its replies, not tool calls or tool output), re-read with each question; from the workspace header button, a selection outside an agent, or a non-Claude agent, your Claude Code default. On desktop the window can be moved and resized, and its size, position and text size are remembered. On desktop you can paste images (Cmd/Ctrl+V) or attach files with the paperclip; they are uploaded to a private temp folder on the daemon and Claude reads them from there. They stay there until the OS cleans its temp folder.

Your questions, the thread and any files or tool results Claude reads are sent to Anthropic through your Claude Code login. The thread survives plugin reloads. On desktop and web the last 100 conversations (the last 60 turns of each) are kept in the app's local storage; "History" reopens one, "New" starts another. If storage runs out, tool steps of older conversations are dropped first. Follow-ups go to the same Claude process for 15 minutes after the last answer, so Claude still sees the results of earlier tool calls; after that, or after a model change, Stop, a steer, New or a daemon restart, the thread is resent as text and earlier tool results are gone. On desktop, selecting text anywhere in Paseo shows a small Ask button that opens the floating window on a new conversation with the selection quoted. In an agent's chat two more buttons appear: Ask in new chat opens the same window, but Send starts a new agent in that workspace with the agent's chat history (its messages, not tool calls) and your question, and opens its tab; Quote adds the quoted selection to the end of that agent's message box. Quoted text goes to an agent that runs tools without prompts, so instructions inside it, for example from a web page another agent read, can be acted on.
