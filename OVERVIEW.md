Adds an "Ask" button to the workspace header and to each agent's composer. It opens a floating window (full screen on phones) where you type a question and get an answer, with follow-ups in the same thread. While Claude works you see its tool calls as they happen, stop it, or send another message, which steers, queues or interrupts per Paseo's Default send setting, with the same keys as the main composer; the Ask button spins meanwhile and shows a dot when an answer arrives with the window closed. Images the answer links to are shown inline.

Answers come from the Claude Code CLI (`claude -p`) on the daemon machine, so `claude` must be installed and logged in there. It runs like an agent in the main window: your Claude Code settings, skills, plugins and MCP servers, full tool access without permission prompts (`bypassPermissions`), in your home directory: it can search the web, read and change files and run commands. It uses the same Claude model and effort as the agent whose composer opened it; from the workspace header button, a selection outside an agent, or a non-Claude agent, your Claude Code default. On desktop the window can be moved and resized, and its size, position and text size are remembered. On desktop you can paste images (Cmd/Ctrl+V) or attach files with the paperclip; they are uploaded to a private temp folder on the daemon and Claude reads them from there.

Your questions, the thread and any files or tool results Claude reads are sent to Anthropic through your Claude Code login. The thread survives plugin reloads; on desktop and web its last 60 turns are also kept in the app's local storage, so it comes back after an app reload. On desktop, selecting text anywhere in Paseo shows a small Ask button that opens the window with the selection quoted. Click an attached image to view it full size.
